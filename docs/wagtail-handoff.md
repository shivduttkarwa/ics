# Wagtail handoff

Living document. Updated as blocks land; the Wagtail build reads this, `blocks.yaml` and `src/_includes/blocks/`. Motion and the slider, marquee, accordion and news scripts are in `docs/animation.md`.

## How the static build maps to Wagtail

| Static | Wagtail |
|---|---|
| `src/_includes/blocks/<name>.njk` | `templates/blocks/<name>.html`, the block template |
| `value.<field>` | `value.<field>` (same) |
| `{{ value.text \| safe }}` | `{{ value.text\|richtext }}` |
| `{% set img = value.image %}{% include "snippets/image.njk" %}` | `{% image value.image fill-WxH %}` |
| `{% set btn = … %}{% include "snippets/button.njk" %}` | `{% include "snippets/button.html" with btn=… %}` |
| `partials/stream.njk` loop | `{% for block in page.body %}{% include_block block %}{% endfor %}` |
| `src/_data/pages/<page>.json` | the page's fields + StreamField |
| `src/_data/site.json` | site settings and snippets |
| `blocks.yaml` | the StreamField block definitions |
| `dist/assets/css/main.css`, `dist/assets/js/main.js`, from `npm run build` | copied as-is into the Wagtail static files; never edited there |

Nunjucks → Django differences to expect: `loop.index0` → `forloop.counter0`, `loop.first` → `forloop.first`, `{% else %}` in a `for` → `{% empty %}`, `{% set %}` → `{% with %}`, `| length` → `|length`, `| default(x)` → `|default:x`.

Type scale on phones and tablets: below 992 the root is the browser's own size (`font-size: 100%` in `_base.less`), so a design px is a CSS px and the phone frames (430) map one to one. From 992 the fluid root takes over and scales the 1440 design with the window: 16px at 1440 wide, up to 18.67 at 1920, and on a laptop shorter than 812 (the home hero's copy and foot at 16px) down with the height to a 13px floor, so the first screen holds the hero as drawn. The four 14px styles (body 4, breadcrumb, label, video label) hold the 12px text floor there. Tablets (768–991) have no Figma frames: the phone layouts carry on, with a few two-column steps from `md`.

Titles: italic words are `<em>` inside the heading (Ulises Light → Light Italic, Book → Book Italic). In Wagtail a title field that carries emphasis is a RichTextBlock limited to `italic`, rendered without its `<p>`. Where the static data carries a `<br>`, that is the designer's forced line for the 1440 column; it applies from lg only and Wagtail titles can leave it out.

Links: no `href="#"` anywhere. A link whose `url` is empty renders as an `<a>` with no `href` (`{% if btn.url %} href="{{ btn.url }}"{% endif %}`), so it keeps its look but goes nowhere and drops out of the tab order. Keep that test in the Django templates and never use `|default:'#'`.

Focus rings: only for keyboard users. `initFocusMode()` in `ui.js` adds `is-keyboard` to `<html>` on a key press and takes it off on any tap or click; the outline in `_base.less` applies only under it, in `--focus-ring` (canopy; a dark section sets it to moss).

Search engines: `head.njk` carries `<meta name="robots" content="noindex, nofollow">` so the staging copy stays out of search results. Leave it out of the live base template.

Placeholders left in the data, for the client to replace: every `url` is empty; the quotes are "Example Name / ICS Parent"; the slide figures are "XX%" (a figure with no digits is left alone by the counter); FAQ answers 2–5 are "[TBC]"; the USP, journey and news photos include stand-ins where Figma draws none (see each block); `video` is empty everywhere (Figma's video fills cannot be exported).

## Snippets

### Button (`snippets/button.njk`)
`btn = { text, url, style, size, icon }`. `style` is one of the kit's variants (`moss`, `canopy`, `white`, `beach`, `glass`, `outline-white`, `outline-canopy`, `outline-moss`, `outline-glass`; see `docs/design-system.md`), `size` is empty or `small`. `icon`: empty gives the dot that grows into an arrow on hover, taking no more height than the small dot, so a button sized to its label never grows taller (Figma's hover `15841:13704`: the dot 42 at 5 in, the label 15 after it, the button 12 wider; a button pinned to the end of its row, as the USPs' and the news block's, grows past that end through `.btn-grow-past-end()`, so it too grows to the right); `"none"` drops the dot (Figma's outline buttons carry none); `"arrow"` is Figma's plain "Button": no dot, the label then a trailing arrow, 40 tall (44 on touch), the arrow nudging 3px right on hover. `plain` (set before the include) also drops the dot, for templates that decide it themselves (the header pill, the hero's CTA bar, the employment band's second button). The dot and the arrow are the `icon-arrow-right` sprite icon, so keep `partials/icons.njk` in the base template. The menu and footer draw the small button 30 tall (`.btn-sm` overridden there), with the 44px hit area from `.tap-area()`.

`icon: "open"` draws the dot already grown into the 42 circle with its arrow (`btn--open`), as Figma's "Download Our 2025 HSC results" button, which is the hover variant placed at rest; its hover nudges the arrow 3px instead. Drop the flag for the ordinary dot.

### Bullets (`snippets/bullets.njk`, `_bullets.less`)
Figma's "Bullet Point with Icon" list, shared by the pillar (`bullets`) and `bullet_list`: `bullets = [{ icon, title, text }]` set before the include (`{% include "snippets/bullets.html" with bullets=value.bullets %}` in Django). Each row is a 46 square (radius 5, `--color-moss-20`) holding a 30 moss glyph (`icon-<name>`), 22 of air, the bold line (Museo Sans 700 16 / 1.4) and any light line(s) (300 16 / 1.4); a one-line row centres on its icon, a row with `text` aligns to the top. Rows 20 apart; the text takes the block's colour (the pillar's title colour, coal in `bullet_list`). The list fades up row by row (`data-anim-group="fade-up"`).

### Image (`snippets/image.njk`)
`img = { src, alt, width, height }`, lazy by default (`loading` overrides). Photos in sliders and marquees are loaded a screen early by `initEagerPhotos()` and the slider scripts, so a card never arrives blank.

### Arrows (`_arrows.less`)
Figma's "Arrow" circle: `<button class="arrow-btn arrow-btn--prev|--next">` holding `icon-arrow-right` (the prev one mirrored), 52 round, moss 30% with a moss arrow, recoloured per block through `--arrow-bg`, `--arrow-ink`, `--arrow-bg-hover`, `--arrow-ink-hover`. The `.arrows` wrapper puts a pair 10 apart.

## Layout

### Rounded feet (`04-layout/_sections.less`)
Figma rounds the foot of a section (20) and tucks the next one under it, so the next section's colour shows in the corners. A block whose section has the corners carries `rounded-foot` on its root; the section after it gets a `::before` that reaches 20 up behind the corners in its own background (`background: inherit`), at `z-index: -1`. That only works while `main` and `body` make no stacking context (no `transform`, `filter`, `isolation` or `z-index` on them), and the next section's background must be a plain colour. Carried by: hero, announcement, the three pillars, FAQs and the footer's upper band. The USPs block must not carry it (Pillar #01 carries on its canopy ground); Pillar #03's foot tucks 24 into the journey block, whose top padding allows for it.

### Scroll lock (`lockScroll()` in `ui.js`, `_header.less`)
`html.is-locked` hides the page's scrollbar and pads `body` and `.site-header` by the gutter `lockScroll()` measured first (`--scrollbar-gutter`), so nothing shifts while the menu is open. Lenis is stopped for the same time.
